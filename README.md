# Jah-Bless
mod for radio and follower quest in Fallout 4

## Имена сохранений

После обновления игра дописывает к сейву хвост `_00000000SM...`. В русской локализации из-за этого игра не запускается, пока хвост не стереть руками.

`Tools\JahSaveNameFix.bat` следит за `Документы\My Games\Fallout4\Saves` и после выхода из игры сам переименовывает файл обратно в слот: `Exitsave0.fos`, `Autosave2.fos`. Пока Fallout4 запущен, файлы не трогает. Ярлык на bat можно положить в автозагрузку.
